# HeroIllustrationLeft

Cụm minh họa trái của hero: hoa mặt vuông xanh dương, sao, tim, đồng xu, lá. Đặt absolute bên trái tiêu đề hero với class `hero-illo left`; tự ẩn dưới 760px.

```jsx
<section className="hero">
  <HeroIllustrationLeft className="hero-illo left" />
  <HeroIllustrationRight className="hero-illo right" />
  <h1 className="hero-title">Việc làm thêm cho sinh viên</h1>
</section>
```
