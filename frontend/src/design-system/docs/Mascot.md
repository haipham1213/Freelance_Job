# Mascot

Nhân vật hoạt hình nhỏ, nét #343433, tô một màu nhấn phẳng: `blob` xanh lá, `triangle` vàng, `cloud` xanh dương, `flower` hồng. Điểm nhấn trong card tính năng, trạng thái trống, trang lỗi.

```jsx
<div className="card stack">
  <Mascot kind="triangle" size={64} />
  <h3 className="h-md">Ứng tuyển minh bạch</h3>
</div>
```
